
ABSTRACT

Inflation forecasting is critical for monetary policy, yet machine learning 
studies have focused predominantly on short horizons. This study investigates 
5-year-ahead inflation forecasting using the Global Macro Database (GMD), 
which provides harmonized annual data for 52 countries spanning five decades 
(1970-2025). We construct a leakage-free pipeline with a 10-year input window 
of 8 macroeconomic variables and a 5-year forward-average inflation target, 
and evaluate six models under two-fold temporal cross-validation.

Our central finding is that the persistence benchmark — using the last 
5-year average as the forecast — dominates machine learning methods on 
average (mean R² = 0.66 across folds), while tree-based ensembles 
(XGBoost, Random Forest, Gradient Boosting) achieve mean R² between 
0.49-0.51 with high cross-fold variance. A CNN-LSTM-Attention hybrid 
achieves mean R² = 0.29, improving substantially in the fold with 
larger training data (R² = 0.47 at 1,015 samples vs 0.12 at 775 samples). 
Ridge regression fails catastrophically due to non-linearity in the 
log-transformed target.

Our results replicate the classic Atkeson-Ohanian (2001) finding in a 
modern machine learning context, demonstrating that even sophisticated 
methods cannot reliably beat simple persistence for medium-horizon inflation 
forecasting. We provide the first leakage-free ML benchmark using GMD, 
comprehensive model comparison with proper baselines, and empirical 
evidence that sample size, not model complexity, is the binding constraint 
for ML-based inflation forecasting.

Keywords: inflation forecasting, persistence, machine learning, 
Global Macro Database, temporal cross-validation, medium-horizon
